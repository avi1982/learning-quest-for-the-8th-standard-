About this project

Learning Quest is a Community Engagement Project (CEP) built for a government school's Class 8 students. It was designed directly from a 70-student survey: Science and Math came out as the hardest subjects, "not enough practice" was the top reason topics feel difficult, and most students said they'd enjoy learning through a game or quiz — so that's exactly what this is.

Guide for teachers

  1. Open this page's link on any phone, tablet or computer — no install needed.
  2. Send students to the Learn tab first for a quick explanation of each topic.
  3. Let them try the Play tab — each attempt draws 10 random questions, so replaying stays fresh.
  4. Check the Reports tab together to see attempts, best scores, and improvement over time.
  5. On days with no internet, use the printable worksheets below as a paper backup.

Printable worksheet (offline backup)

Prints all questions and answers for one subject on paper — useful when internet is patchy.

Accessibility

Use the A−/A+ buttons at the top to change text size, and the language button to switch the menus and buttons between English and Hindi. (Quiz questions themselves are currently in English only.)
